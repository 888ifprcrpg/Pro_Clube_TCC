# Pro_Clube_TCC

O ProClube+ é um sistema web desenvolvido com o objetivo de modernizar a gestão de clubes e associações recreativas, esportivas e sociais, centralizando processos administrativos em uma única plataforma. O projeto busca substituir procedimentos manuais por uma solução digital mais eficiente, segura e acessível, permitindo o gerenciamento de sócios e dependentes, controle de mensalidades e inadimplência, reservas de espaços, organização de eventos, envio de notificações automáticas, emissão de documentos digitais, solicitação de suporte e geração de relatórios administrativos. A aplicação está sendo desenvolvida utilizando HTML, CSS e JavaScript no front-end, PHP (ou Java) no back-end e MySQL como sistema gerenciador de banco de dados. O ProClube+ faz parte de um projeto acadêmico do curso Técnico em Informática do Instituto Federal do Paraná (IFPR) e tem como foco aplicar conceitos de engenharia de software, banco de dados e desenvolvimento web na criação de uma solução prática para a administração de clubes, proporcionando maior organização, redução de custos operacionais e uma melhor experiência para administradores, funcionários e sócios.
